# Biblioteca Full Stack

Projeto educacional feito com HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Clique em **Ler livro** para acessar um dos 12 livros.
4. Use a busca e o filtro para encontrar assuntos.
5. Marque livros como concluídos; o progresso fica salvo no navegador via `localStorage`.

## Conteúdo
1. Web do zero: HTML, CSS, JavaScript, lógica e DOM
2. Git, GitHub, npm, JavaScript assíncrono e TypeScript
3. React: componentes, props, estado, effects e projeto de clima
4. Tailwind, Context API, Zustand e chat offline
5. Node.js, Express, PostgreSQL, Docker e API
6. SQL, modelagem relacional e Drizzle ORM
7. Zod, JWT, bcrypt, autenticação e testes
8. SOLID, DTOs, Use Cases e Clean Architecture
9. Uploads, imagens, email, logging, likes e replies
10. Redis, BullMQ e integração frontend/backend
11. Stripe, Playwright, CI/CD e deploy
12. Projeto final: sistema de agendamento com integração WhatsApp

## Observações
- Os exemplos são didáticos e podem exigir instalação de dependências ou adaptação antes de rodar.
- Integrações de pagamento e WhatsApp devem ser implementadas com serviços oficiais, chaves protegidas e ambientes de teste.
- O progresso é local ao navegador e não sincroniza automaticamente entre dispositivos.
